# 塔吉多 GitHub Actions 签到

「塔吉多签到」每天北京时间 **02:00** 执行塔吉多 APP 和已绑定游戏角色的签到。项目位于 [`taygedo/`](../taygedo)，源自上游提交 [`cc8c036`](https://github.com/zzstar101/taygedo-auto-attendance/tree/cc8c036d0a66802a39b4ecc10f7095e38f695151)，许可证见 [MIT](../taygedo/LICENSE)。

## 首次配置

1. 在 GitHub 创建 [fine-grained personal access token](https://github.com/settings/personal-access-tokens/new)。仓库访问选 **Only select repositories → auto-signin**，仓库权限选 **Secrets → Read and write**。它用于把刷新后的账号凭据写回本仓库。
2. 在仓库的 [Actions Secrets](https://github.com/ShengjieLi-CN/auto-signin/settings/secrets/actions) 添加三个 **Repository secrets**。

   | 名称 | 内容 |
   | --- | --- |
   | `GH_SECRET_UPDATE_TOKEN` | 上一步创建的 GitHub 令牌 |
   | `TAYGEDO_LOGIN_PHONE` | 塔吉多登录手机号 |
   | `TAYGEDO_LOGIN_PASSWORD` | 塔吉多登录密码 |

3. 在 [塔吉多登录](https://github.com/ShengjieLi-CN/auto-signin/actions/workflows/taygedo-login.yml) 选择 **Run workflow**。首个账号使用默认值即可。登录成功后会生成 `TAYGEDO_ACCOUNTS` 和 `TAYGEDO_CREDENTIAL_KEY`。
4. 登录成功后，在 [塔吉多签到](https://github.com/ShengjieLi-CN/auto-signin/actions/workflows/taygedo-attendance.yml) 选择 **Run workflow**，取消勾选 `verify_only` 来验证真实签到。日志会显示成功、失败和跳过的账号数。

添加更多账号时，更新手机号和密码 Secret 后，以不同 `account_id` 依次运行「塔吉多登录」。登录成功后，当次密码已加密保存，仓库中的手机号和密码 Secret 可按需删除。GitHub 令牌到期后需要更新 `GH_SECRET_UPDATE_TOKEN`。

已有塔吉多账号 JSON 时，可直接将其保存为 `TAYGEDO_ACCOUNTS`。若其中有 `encryptedPassword`，还需设置对应的 `TAYGEDO_CREDENTIAL_KEY`。

## 可选设置

默认执行 APP 和游戏签到。要启用金币任务或领取云异环时长，可在仓库的 Actions **Variables** 分别将 `TAYGEDO_COIN_TASKS` 或 `TAYGEDO_CLOUD_DURATION` 设为 `true`。

勾选 `verify_only` 可随时验证依赖安装、自动化测试及 TypeScript 构建。签到凭据配置完成前，定时运行会跳过签到步骤。
